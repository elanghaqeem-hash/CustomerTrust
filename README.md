# CustomerTrust

Repository utama (**Single Source of Truth**) untuk proyek CustomerTrust.

## Aturan kerja ChatGPT ↔ GitHub

Seluruh perubahan *file proyek* yang dikerjakan melalui ChatGPT diarahkan ke repository ini, dengan branch utama `main`.

- **Baca sebelum mengubah:** periksa versi terbaru file dari GitHub.
- **Simpan perubahan nyata:** buat commit dan push melalui konektor GitHub di percakapan yang sama setelah perubahan diselesaikan dan diperiksa.
- **Verifikasi:** pastikan commit berhasil dan laporkan file serta tautan commit; jangan mengklaim file sudah tersinkron jika belum berhasil.
- **Jaga integritas:** jangan menimpa perubahan terbaru, jangan menghapus file tanpa instruksi, jangan memasukkan kata sandi/token/data sensitif.
- **Tinjauan perubahan berisiko:** perubahan besar atau berisiko boleh melalui branch dan pull request sebelum merge sesuai proteksi repository.

Petunjuk rinci untuk agen pengembang berada di [AGENTS.md](AGENTS.md).

> Catatan: perubahan dalam teks percakapan tidak tersimpan di GitHub dengan sendirinya. Sinkronisasi terjadi ketika agen menjalankan operasi GitHub pada file yang dimaksud.
